Put your gift card pictures in this folder.

Suggested file names (match the rules at the bottom of style.css):
  steam.png
  binance.png
  bilibili.png
  dramabox.png
  mobile-legends.png
  playstation.png
  nintendo-eshop.png
  psn-sgd.png
  ymir.png
  blizzard.png
  xbox.png
  netease-pay.png
  google-play.png
  minecraft.png
  switch-online.png

Then open style.css, find the rule for the card (for example .art-binance),
and remove the comment marks around the --pic line.
PNG, JPG, WebP and SVG all work. A transparent PNG about 400x300 looks best.
